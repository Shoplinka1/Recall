GOAL:

Make Recall behave like a genuinely useful learning assistant/teacher.

For sufficiently large source material, Recall should intelligently identify the important concepts and create a varied practice set that helps the user actually understand and remember the material.

It should NOT simply create more questions.

QUALITY REQUIREMENTS:

1. Generate as many useful questions as the source genuinely supports.
2. Do not artificially cap substantial material at two questions.
3. Cover multiple important concepts and source sections.
4. Avoid asking essentially the same question repeatedly.
5. Avoid repeatedly targeting the same answer/concept.
6. Detect exact duplicates.
7. Detect near-duplicates that test essentially the same knowledge.
8. Use different question forms when the source supports them:
   - definition
   - explanation
   - mechanism
   - cause/effect
   - comparison
   - application
   - scenario
   - relationship
   - MCQ
   - true/false
   - short-answer
9. Prefer understanding/application over repetitive memorization.
10. Never invent information that is not supported by the user's material.
11. Every question must have valid source/section provenance.
12. Every expected answer must be supported by the source.
13. MCQ distractors must be plausible but clearly distinguishable and grounded.
14. True/false statements must be directly supported or contradicted by the source.
15. Short-answer questions must remain compatible with the existing Step 5 answer matcher.
16. Preserve PostgreSQL/Drizzle persistence.
17. Preserve authentication and server-side ownership.
18. Preserve Step 6 mastery/confidence/weakness functionality.
19. Never use demo data to increase question variety.

IMPORTANT INTELLIGENCE REQUIREMENT:

Do NOT just increase the number requested from the AI.

The system should reason about the available source material and distribute questions across the concepts actually present.

For example, if a document contains:
- Concept A
- Concept B
- Concept C
- Concept D

the generated practice set should not contain six slightly different questions about Concept A.

It should deliberately cover A, B, C and D where sufficient evidence exists.

Also distinguish between:
- testing the same fact in different wording
- genuinely testing a different aspect of understanding.

Only the latter should count as useful diversity.
