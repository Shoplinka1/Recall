10. PAYSTACK CHECKOUT FLOW
==================================================

Flow:

User clicks:

"Start Recall Pro"

↓

Frontend calls:

POST /api/payments/paystack/initialize

with:

monthly

or

annual

↓

Server:

1. Authenticates the user.
2. Determines the correct Paystack plan code.
3. Uses the authenticated user's email.
4. Initializes the Paystack transaction.
5. Includes the appropriate subscription plan.
6. Returns the Paystack authorization URL.

↓

Frontend redirects the user to Paystack.

↓

User completes payment.

↓

Paystack redirects to Recall.

↓

Recall verifies the transaction server-side.

↓

Recall updates the local subscription state.

IMPORTANT:

Never activate Pro simply because the browser returned successfully.

Never trust:

localStorage
query parameters
frontend state
client-side flags

Only server-side verified Paystack payment/subscription information may activate Pro.
